HOW TO INSTALL

  1. Download the launcher for your computer and unzip it.
  2. Start Orbit Horizon Launcher and press INSTALL. It downloads the game for you.
  3. Press PLAY. Next time the launcher updates the game by itself.

Mac: the first time, right-click the launcher → Open → Open (it isn't signed by Apple yet).
Windows: if SmartScreen warns you, click "More info" → "Run anyway".

THE GAME

A pixel survival game in space. Dig, build a home base, tame puffles, meet survivors and goblins, clear cursed keeps and swamp temples, and fly your ship through an endless galaxy, all the way to strange alien worlds. Play alone or with friends. In English and Vietnamese.
